Konfigurasi DHCP Server

Panduan Praktis pada Sistem Operasi Debian 13

Menggunakan isc-dhcp-server

Disusun oleh AI Assistant

📋 Persiapan Awal (IP Statis)

DHCP server wajib memiliki IP statis (tetap). Ubah konfigurasi network interfaces server Anda.

Buka file konfigurasi:

sudo nano /etc/network/interfaces 
auto enp0s3
iface enp0s3 inet static
    address 192.168.10.1
    netmask 255.255.255.0

Setelah itu, restart jaringan dengan sudo systemctl restart networking.

🛠️ Langkah 1: Install Paket

Lakukan update pada repositori sistem Anda dan install paket isc-dhcp-server.

sudo apt update
sudo apt install isc-dhcp-server -y

Paket ini adalah program standar yang akan menyebarkan IP Address secara otomatis ke seluruh komputer klien di jaringan Anda.

🛠️ Langkah 2: Tentukan Antarmuka (Interface)

Kita harus memberi tahu DHCP server, port/antarmuka mana yang akan digunakan untuk menyebarkan IP.

Buka file default DHCP:

sudo nano /etc/default/isc-dhcp-server

Cari baris INTERFACESv4 dan isikan nama antarmuka Anda (contoh: enp0s3):

INTERFACESv4="enp0s3"

🛠️ Langkah 3A: Aktifkan Authoritative

Langkah selanjutnya adalah mengatur konfigurasi utama DHCP. Buka filenya:

sudo nano /etc/dhcp/dhcpd.conf

Cari baris #authoritative; (biasanya di bagian atas), kemudian hilangkan tanda pagarnya (#) sehingga menjadi:

authoritative;

Hal ini menjadikan server Debian Anda sebagai pusat DHCP utama di jaringan lokal yang Anda kelola.

🛠️ Langkah 3B: Konfigurasi Subnet

Pada file yang sama (di bagian paling bawah), tambahkan blok subnet berikut untuk membagikan IP Address (contoh range 10-50):

subnet 192.168.10.0 netmask 255.255.255.0 {
  range 192.168.10.10 192.168.10.50;
  option domain-name-servers 8.8.8.8, 8.8.4.4;
  option domain-name "jaringan.lokal";
  option routers 192.168.10.1;
  option broadcast-address 192.168.10.255;
  default-lease-time 600;
  max-lease-time 7200;
}

🛠️ Langkah 4: Restart & Cek Status

Simpan konfigurasi Anda, lalu terapkan perubahan dengan melakukan restart service DHCP:

sudo systemctl restart isc-dhcp-server

Pastikan layanannya berjalan normal (tanpa error) dengan perintah:

sudo systemctl status isc-dhcp-server
Status harus menunjukkan tulisan active (running).

💻 Pengujian di Komputer Klien

  • Hubungkan komputer klien (Windows/Linux) ke jaringan yang sama dengan server.
  • Pastikan pengaturan IP Address di komputer klien diubah menjadi Obtain an IP address automatically (DHCP).
  • Cek IP Address klien (bisa lewat ipconfig di Windows). Klien seharusnya mendapatkan IP antara 192.168.10.10 hingga 192.168.10.50.
🎉 Konfigurasi Selesai! Klien Anda sudah terhubung secara otomatis.
