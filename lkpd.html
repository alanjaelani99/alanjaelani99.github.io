Konfigurasi Network Adapter pada VMware

Identitas Peserta Didik

A. Tujuan Pembelajaran

  • Menjelaskan fungsi Network Adapter VMware.
  • Membedakan Bridged, NAT, Host-only, Custom, dan LAN Segment.
  • Memilih mode jaringan sesuai kebutuhan lab.
  • Menguji konektivitas Debian Server dan Windows Client.

B. Ringkasan Materi

Network Adapter menentukan cara VM terhubung ke jaringan. Bridged terhubung langsung ke jaringan fisik, NAT berbagi Internet melalui Host, Host-only membuat jaringan privat, Custom memilih VMnet tertentu, dan LAN Segment membuat jaringan virtual terisolasi.

D. Kegiatan 2 — Praktik Host-only

  1. Atur Debian Server ke Host-only.
  2. Atur Windows Client ke Host-only yang sama.
  3. Gunakan contoh IP Debian 192.168.100.10/24 dan Client 192.168.100.20/24.
  4. Uji konektivitas dengan ping.

Debian:

ip addr
ping -c 4 192.168.100.20

Windows:

ping 192.168.100.10

E. Kegiatan 3 — NAT + Host-only

Konfigurasikan Debian dengan Adapter 1 = NAT dan Adapter 2 = Host-only. Uji akses Internet dan koneksi ke Windows Client.

F. Pertanyaan HOTS

  1. Sebuah Debian Server perlu Internet untuk update paket tetapi jaringan praktikum harus terpisah dari LAN sekolah. Mode apa yang dipilih? Jelaskan.
  2. VM harus dapat diakses komputer lain pada LAN fisik. Mode apa yang sesuai? Mengapa?
  3. Apa risiko menggunakan Bridged untuk praktikum DHCP Server?
  4. Mengapa Host-only cocok untuk simulasi DNS, DHCP, dan Web Server?
  5. Bandingkan NAT dan Host-only dari sisi konektivitas dan keamanan.
